## איך משחקים

1. **מחזיקים ומשחררים** כדי להטיל.
2. **כשהמצוף שוקע**, לוחצים.
3. **מחזיקים** כדי לגלגל את הדג.

↑ ↓ עומק · גלגלת בלם · "חנות" לציוד. בטלפון כדאי לשחק לרוחב.

## הסיפור

המשחק בהשראת הסיפור על [יוסף מוקיר שבת](https://www.sefaria.org.il/Shabbat.119a.5?lang=he) (תלמוד בבלי, שבת קיט ע״א), שמצא מרגלית בבטן דג שקנה לכבוד שבת.
